# The tabs of Axis Dashboard

Sigrid Axis Dashboard shows the same measurements in four tabs, from summary to detail. This page gives an overview of the tabs and explains how to read the metrics that all of them share.

## The four tabs

Axis Dashboard has four tabs. Together they go from summary to detail.

| Tab | Question it answers |
|---|---|
| [Dashboard](dashboard.md) | Where does the portfolio stand on AI adoption, speed, and output quality, and which systems stand out? |
| [AI Adoption](ai-adoption.md) | How much of the new code is AI-generated, is that increasing over time, and in which systems? |
| [Speed](speed.md) | Are teams merging more pull requests per developer, and how does that compare with the market? |
| [Output Quality](output-quality.md) | Is the quality of new code holding up, for maintainability, security, and reliability? |

Start with the Dashboard tab. Each of its tiles links to a tab with more detail.

## Portfolio and system view

By default you see aggregate metrics for your whole portfolio. Select a system in a list or a chart to go to a view for that system only. [Navigating Axis Dashboard](navigating.md) explains how to switch, how to choose the period you look at, and how to set a [portfolio filter](definitions.md#portfolio-filter) on a group of systems.
